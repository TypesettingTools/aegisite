### Platform Support

#### Windows

- Report Windows 11 correctly to the update checker.

#### macOS

- Fix a crash on startup on macOS 13 and other macOS releases with an older system libc++.
- Allow Automation scripts to load native modules that aren't signed by Aegisub's developer again.
- Report macOS 11 and later correctly to the update checker.

### Automation

- Fix controls in script dialogs coming out smaller than intended with newer wxWidgets versions.
- Make `include()` and `require()` report the actual syntax error for broken Lua and MoonScript files, rather than the module name or "attempt to call a nil value".
- Fix runtime errors in scripts loaded with `include()` crashing Aegisub on some platforms.
- Fix detection of files starting with a UTF-8 BOM on platforms where `char` is unsigned.
- Add `aegisub.version`, which lets scripts check the version of Aegisub they're running in.

### Bugfixes

- Fix a crash when the video display keeps failing to render, e.g. due to a persistent OpenGL error.
- Make changing underline in the font dialog set `\u` rather than toggling italics.
- Fix the `LayoutResY` computed when resampling a script that has a `LayoutRes` while adding or removing top or bottom borders.

### Improvements

- Let the video, audio, keyframe, and timecode file dialogs start in the current script's folder when the last such file was opened from its script's folder.
- Show each track's language and title in the track selection dialog.
- List only the file types the active audio and video providers support in the file dialogs' filters.

### Translations

- Update the Korean translation.

### Development

- Fix building with LuaJIT's external unwinding and with some GCC versions.
- Build the bundled FFmpeg without unused components.
